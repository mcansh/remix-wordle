# Pitlane

Pitlane adds build tooling, content, styling, and platform integrations to Remix. Remix owns routing, components, and request handling; deployment configuration stays with the host. The `pitlane` package brings the Pitlane packages together under `pitlane/*` imports.

## Find the installed documentation

Start with `node_modules/pitlane/INDEX.md`. Search by the task or import subpath, then follow the relative links:

- Guides explain application workflows.
- Package READMEs describe the corresponding package and its APIs.
- The installed package's exported declarations and TSDoc provide exact API signatures.

For prebuilt Markdown content, search the index for “content” and read the guide it names before choosing an API. For Remix behavior, use `node_modules/remix/INDEX.md`.

Prefer the installed documentation over this skill, memory, or the latest website: it matches the app's installed version. If the index is missing, inspect the installed `pitlane` version and README; an older release may not ship it. Do not upgrade the app just to obtain documentation.
